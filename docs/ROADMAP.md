## 逐步交付

| 阶段 | 交付内容 | 通过条件 |
| --- | --- | --- |
| 0 环境验证 | 默认应用运行 | 真机看到默认页面，记录构建结果 |
| 1 技术验证 | 切换检测、计时、覆盖页原型 | 在 OPPO 上切换、锁屏、恢复并记录结果 |
| 2 数据与规则 | 本地表、配置、当日快照 | 当天不可变、更改次日生效，跨天行为明确 |
| 3 学习解锁 | 计时、完成度、达标解锁 | 两项同时满足才解锁，奖励只记一次 |
| 4 应用限制 | 拦截、白名单、紧急退出 | 必需入口可用，紧急退出到期恢复 |
| 5 积分 | 奖励、惩罚、核销、流水 | 不负分、不超上限、重试不重复结算 |
| 6 可靠性 | 验证、日志、备份、恢复 | 导入校验、重启、权限关闭、异常恢复通过 |
| 7 试用 | 真机验收记录与演示 | 逐项记录 AC-01～AC-17 结果和已知问题 |

## 测试记录格式

每条记录应包含：日期、手机与系统版本、代码提交、操作步骤、预期、实际结果、通过/失败和证据。性能指标使用实测数据，不预先声明达标。
