# StudyUnlock · 学习解锁娱乐

面向个人自用的 Android 自律工具：先完成学习目标，再解锁当天的娱乐应用。

> **开发中 / 首个业务原型。** 已实现本地规则、跨天结算、学习与娱乐计时、无障碍拦截、紧急放行、积分流水和 JSON 备份，仍需在 OPPO Find X8 Pro 上完成端到端验收。

## 项目动机

针对学习期间容易切换到短视频和游戏的问题，设计一个本地运行的自律工具。将学习应用使用时长与手动填写的完成度结合，在两者同时达标后解锁娱乐应用，并以虚拟积分记录奖励和惩罚。

## V1 原型功能

- 自选学习应用和娱乐应用，配置次日生效，当日规则快照锁定。
- 累计学习应用的前台活跃时长，手动录入 0～100% 完成度。
- 时长和完成度同时达标后，当天解锁娱乐应用。
- 未达标显示拦截页，提供每日限次的 5 分钟紧急退出。
- 虚拟积分奖励、次日惩罚、现实奖励核销和完整流水。
- 随机验证、权限状态提醒、时间变化与异常日志。
- 本地存储与 JSON 文件导入、导出，不做账号或云同步。
- 在设置中选择照片作为应用内壁纸，支持预览和恢复默认。

## 本地运行

1. 安装支持本项目 Android Gradle Plugin 的 Android Studio 和对应 Android SDK。
2. 克隆仓库，用 Android Studio 打开项目根目录。
3. 等待 Gradle 同步；首次下载依赖需要网络。使用 Android Studio 配套的兼容 JDK。
4. 在 Android 15 或以上手机开启 USB 调试，连接电脑并授权。
5. 选择 `app` 和手机，点击 Run。当前会打开今日、记录、设置三个入口。首次使用需在设置中授权使用情况访问和无障碍服务，再配置学习与娱乐应用。

命令行构建（Windows，需配置兼容 JDK 和 SDK）：

```powershell
.\gradlew.bat assembleDebug
```

仓库不包含本机 `local.properties`、签名密钥、构建产物或个人备份。`local.properties` 可由 Android Studio 在本机生成。

## 设计重点与限制

开发重点是计时状态机、每日快照、积分幂等结算、进程中断恢复及 OPPO 后台行为验证。“幂等结算”表示重复启动或重试不会对同一天重复加分、扣分。

普通 Android 应用无法保证在强行停止、卸载、关闭权限或厂商结束后台后仍继续拦截。本项目定位为自律辅助工具；拦截速度、计时精度和重启恢复均需实测，尚无性能达标结论。
